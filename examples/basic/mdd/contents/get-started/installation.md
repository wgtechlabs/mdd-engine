# Installation

Create `mdd/contents/index.md` inside your project, then compile the project using `compileProject`.

## Configuration

Add `mdd/config.json` only when you need a site title, custom paths, or a selected theme.

:::details[What about hosting?]
The engine is headless. Hosting and static export belong to the separate mdd application.
:::
